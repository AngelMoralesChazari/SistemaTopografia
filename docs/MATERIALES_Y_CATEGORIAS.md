## 🚀 Cómo aplicar y sembrar estos datos en la base de datos

Para reflejar este catálogo completo en Firestore:

1. Ejecuta el comando de siembra:
```powershell
npm run seed:equipment
```
2. La rutina registrará las **9 categorías oficiales**, archivará automáticamente los ítems anteriores de prueba y cargará todos los materiales con sus códigos internos, marcas, modelos, series y cantidades exactas.
